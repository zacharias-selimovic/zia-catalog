# zia model catalog

Public model metadata consumed by the zia local AI desktop app.

The catalog contains names, resource estimates, task tags, source/license links, compatibility requirements, and limited evaluation status. It contains no app source, model weights, credentials, or user data.

The current models remain quality candidates. Reviewed languages mean limited tasks were checked, not certified proficiency. Resource estimates and single-machine observations do not guarantee suitability or answer accuracy.

The app refreshes explicitly, validates version/schema/size, and keeps its last accepted offline cache. A catalog never executes code or installs models automatically. Every content change requires a higher catalog version.

Model licenses are identified in each entry and apply to the corresponding upstream models. This repository distributes metadata only.
